# OF_SF 登陆器 · Windows x64

1. 更新 TapTap 国服 PC 1.1.12 并完整解压登陆器。支持 11 月 7 日和 11 月 25 日资源清单。双击 **OF_SF 登陆器.exe**。在「服务器地址」输入服主提供的 IP 或域名，可加端口；省略端口使用 **18443**。先前保存的连接和证书会自动沿用。已有旧版时，把单文件 EXE 放在原文件夹的上一级，或在原文件夹内完整解压 ZIP 进行升级。
2. 已有账号选择「登录」。新玩家点「注册」，账号为 3–40 位汉字、英文字母、数字、下划线、点或短横线，密码 8–128 个字符。角色名在本区服内唯一，也可以进游戏再起名。「检查账号」可在完成图片验证后确认账号是否可用。验证码过期时可换一张。
3. 首次连接会验证证书域名、有效期及签发链。可通过系统信任或登陆器随附的 Sectigo R46 公有根验证时，会自动进入账号页。私有区服可在「设置」选择服主的 CA 文件，或通过另一渠道核对完整 SHA-256 指纹，输入末 8 位后保存。证书轮换后请向服主核实，再点「重新核对证书」。
4. 要继承进度，请在创建账号后、首次进游戏前点「继承已有存档」。选择全进度备份工具的 ZIP、`snapshot.json` 或结果目录，在预览中核对游戏内显示的 UID、角色名、地点和可恢复内容，再确认。备份文件夹编号可能与游戏内 UID 不同。v1.9 的 ZIP 和 snapshot.json 都可用于继承。区服支持时，探索员使用的鱼竿会绑定到导入后的装备实例，并恢复记录的剩余耐久。若 UID 或角色名已占用，可用本区身份或另起名字。首次进游戏前可在同一界面撤销。旧区服缺少的进度类型会在预览列出。
5. 点「登录并进入游戏」启动原版游戏客户端。在「设置」选择游戏安装目录、渠道启动器目录或 TapTap、Steam 游戏库，登陆器会检查清单与程序指纹。已实测 TapTap 国服 PC 1.1.12。B站和 Steam 渠道尚待实机验证；指纹不匹配时界面会提示版本。首次准备通过 NTFS 硬链接复用资源。登陆器和游戏分属两块盘时，在原游戏盘选择独立工作目录。短暂掉线后，支持续连的区服会在两分钟内允许同一游戏进程恢复角色。会话失效后，请在登陆器重新登录。要玩官服，退出后从原渠道启动器启动。

清理本机副本请先正常退出游戏，再到「设置」点「清除本机游戏副本」。区服角色保存在服主服务器。

每个区服会记住上次成功登录的账号。可在私人电脑勾选「记住密码」，由当前 Windows 用户加密保存。取消勾选会立即清除该区服已保存的密码。要改密，请在登录页选择「修改密码」，输入当前密码与两次新密码后重新登录。忘记密码时请联系管理员。
