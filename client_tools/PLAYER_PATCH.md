# OF_SF 登陆器 · Windows x64

输入区服地址后稍候即可看到在线状态与响应时间。延迟包含本机到区服的一次 TLS 握手和状态查询。「设置 → 连接与证书 → 测试区服连接」可查看可用扩展目录的条目数。旧区服或目录暂时不可用时，仍可登录区服。

可继承原备份记录的星云树节点、页面领奖和成就。若区服仍为 r6，导入预览会列出此次将跳过的星云树记录数。

首次启动若需要热更，r6 登陆器搭配 r6 区服可等候一小时再进图。r5 公网区服可等候五分钟。超过时限请退出游戏，在登陆器重新登录。

1. 更新 TapTap 国服 PC 1.1.12 并完整解压登陆器。支持 11 月 7 日和 11 月 25 日资源清单。双击 **OF_SF 登陆器.exe**。在「服务器地址」输入服主提供的 IP 或域名，可加端口；省略端口使用 **18443**。先前保存的连接和证书会自动沿用。已有旧版时，把单文件 EXE 放在原文件夹的上一级，或在原文件夹内完整解压 ZIP 进行升级。
2. 已有账号选择「登录」。新玩家点「注册」，账号为 3–40 位汉字、英文字母、数字、下划线、点或短横线，密码 8–128 个字符。角色名在本区服内唯一，也可以进游戏再起名。「检查账号」可在完成图片验证后确认账号是否可用。验证码过期时可换一张。
3. 首次连接会验证证书域名、有效期及签发链。可通过系统信任或登陆器随附的 Sectigo R46 公有根验证时，会自动进入账号页。私有区服可在「设置」选择服主的 CA 文件，或通过另一渠道核对完整 SHA-256 指纹，输入末 8 位后保存。证书轮换后请向服主核实，再点「重新核对证书」。
4. 要继承进度，请在创建账号后、首次进游戏前点「继承已有存档」。选择全进度备份工具的 ZIP、`snapshot.json` 或结果目录，在预览中核对游戏内显示的 UID、角色名、地点和可恢复内容，再确认。备份文件夹编号可能与游戏内 UID 不同。v1.9 的 ZIP 和 snapshot.json 都可用于继承。配套区服也能恢复备份中可核实的个人签名。区服支持时，探索员使用的鱼竿会绑定到导入后的装备实例，并恢复记录的剩余耐久。若 UID 或角色名已占用，可用本区身份或另起名字。首次进游戏前可在同一界面撤销。旧区服缺少的进度类型会在预览列出。
5. 点「登录并进入游戏」启动原版游戏客户端。在「设置」选择游戏安装目录、渠道启动器目录或 TapTap、Steam 游戏库，登陆器会检查清单与程序指纹。可先点「检查客户端版本」，此操作在本机完成。已实测 TapTap 国服 PC 1.1.12；B站国服 1.1.12.0 与 Steam 国际版 Build 26178963 均可识别安装文件，两个渠道的私服进图仍待验证。首次准备通过 NTFS 硬链接复用资源。登陆器和游戏分属两块盘时，在原游戏盘选择独立工作目录。短暂掉线后，支持续连的区服会在两分钟内允许同一游戏进程恢复角色。会话失效后，请在登陆器重新登录。要玩官服，退出后从原渠道启动器启动。

**渠道登录。** 第一次启动 TapTap 原版可能会弹出 NEKOTAN 窗口，有 TapTap 账号可以选「TapTap登录」。区服密码只在 OF_SF 登陆器输入。PC 版渠道绑定见[运营方说明](https://www.taptap.cn/moment/656591245195346144)。

**全屏和黑屏恢复。** 退出游戏，在登陆器「设置 → 游戏显示模式」选择「无边框全屏」并保存。如仍黑屏，选「窗口（1280 × 720，黑屏恢复）」再启动。选「跟随游戏设置」可恢复使用游戏保存的窗口状态。

清理本机副本请先正常退出游戏，再到「设置」点「清除本机游戏副本」。区服角色保存在服主服务器。

每个区服会记住上次成功登录的账号。可在私人电脑勾选「记住密码」，由当前 Windows 用户加密保存。取消勾选会立即清除该区服已保存的密码。要改密，请在登录页选择「修改密码」，输入当前密码与两次新密码后重新登录。忘记密码时请联系管理员。

## Mod 扩展

1. 选好原游戏目录，退出私服游戏，进入「设置 → Mod 扩展」。
2. 点「安装扩展」。首次使用时，按提示复制私服游戏副本路径并打开 MelonLoader 的官方安装页。用其安装程序在该副本安装加载器，回到登陆器再点一次「安装扩展」。
3. 在线安装会校验并取用上游宿主和独立目录。已有相同版本的文件会复用；遇到其他版本时会保留现有文件并提示。也可以点「选择本地安装包」，依次选择目录 ZIP 和宿主 ZIP。已装配套宿主时可取消第二次选择。[区服目录 ZIP](https://github.com/YCLiuge/OF_Contracts/releases/download/v0.1.0/OF_SF-ModCatalog-0.1.0-Windows.zip) · [宿主 mod.zip](https://raw.githubusercontent.com/jianx14/overfiled-mod/eac420fcacc4cb48e09746ef2b5f7ca760d00a76/mod.zip)
4. 「上游项目」可查看宿主更新。用登陆器进入游戏，按 **Alt+9**，输入 `ofcatalog` 查看区服发布的内容。切换区服后再次从登陆器进入游戏，会自动使用新地址及对应的证书。
