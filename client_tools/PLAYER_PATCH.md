# OF_SF 登陆器 · Windows x64

1. 更新 TapTap 国服 PC 1.1.12 并完整解压登陆器。支持 11 月 7 日和 11 月 25 日资源清单。双击 **OF_SF 登陆器.exe**。在「服务器地址」输入服主提供的 IP 或域名，可加端口；省略端口使用 **18443**。先前保存的连接和证书会自动沿用。
2. 已有账号选择「登录」。新玩家点「注册」，账号为 3–40 位字母、数字、下划线、点或短横线，密码 8–128 个字符。角色名在本区服内唯一，也可以进游戏再起名。「检查账号」可在完成图片验证后确认账号是否可用。验证码过期时可换一张。
3. 首次连接优先验证系统信任的证书。私有区服可在「设置」选择服主的 CA 文件，或通过另一渠道核对完整 SHA-256 指纹，输入末 8 位后保存。证书轮换后请向服主核实，再点「重新核对证书」。
4. 要继承进度，请在创建账号后、首次进游戏前点「继承已有存档」。选择全进度备份工具的 ZIP、`snapshot.json` 或结果目录，预览 UID、角色名、地点和可恢复内容，再确认。若 UID 或角色名已占用，可用本区身份或另起名字。首次进游戏前可在同一界面撤销。旧区服缺少的进度类型会在预览列出。
5. 点「登录并进入游戏」启动原版游戏客户端。登陆器会查找 TapTap 安装，也可在「设置」指定含 `launcher.exe` 的目录。首次准备通过 NTFS 硬链接复用资源。登陆器和游戏分属两块盘时，在原游戏盘选择独立工作目录。会话失效后可重新登录。要玩官服，退出并从 TapTap 启动。

清理本机副本请先正常退出游戏，再到「设置」点「清除本机游戏副本」。区服角色保存在服主服务器。
